# Contributing to UA-IE Car Scout

Thank you for contributing!

## 🚀 Setup & Guidelines

1. Set up backend & scrapers:
   ```bash
   cd api
   npm install
   npm test
   ```
2. Set up web frontend:
   ```bash
   cd ../web
   npm install
   npm run build
   ```
3. Test taxation engine logic against official Revenue VRT bands before committing.
